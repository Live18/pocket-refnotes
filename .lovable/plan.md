## Goal

Create a self-contained demo route at `/playground/animations` that showcases every major `tw-animate-css` utility live, so you can preview each effect in the running app and pick the ones you want to adopt.

## What I'll build

**New route file:** `src/routes/playground.animations.tsx`

A scrollable, mobile-first page organized into labeled sections. Each section shows the effect plus the exact class string used, so it doubles as a copy-paste reference.

### Sections in the demo

1. **Entrance animations** — fade-in, slide-in (all 4 directions), zoom-in, combo. Each tile has a "Replay" button that remounts the element so you can re-trigger the animation.
2. **Direction & distance** — slide-in-from-{top,bottom,left,right} at distances 2, 8, 16 side-by-side.
3. **Zoom & spin** — zoom-in-50/95, spin-in-90, plus continuous `animate-spin`.
4. **Always-on loops** — `animate-pulse`, `animate-bounce`, `animate-ping` (mentor-notification dot mock).
5. **Timing & easing** — same fade-in at duration-150, 300, 700, 1000 with different easings, shown in a row.
6. **Hover / tap micro-interactions** — `hover:scale-105`, `active:scale-95`, group-hover chevron slide. Tactile on mobile.
7. **Wizard step preview** — a mini 3-step flow with Next/Back buttons that uses `slide-in-from-right-8` forward and `slide-in-from-left-8` back, mimicking the journal new-entry wizard.
8. **Skeleton loader** — a fake archive list using `animate-pulse` blocks.
9. **Notification ping** — a bell icon (lucide) with an `animate-ping` ring behind it.

Each demo card uses the existing `Card` component for consistent styling and the project's dark theme tokens.

### Replay mechanism

A simple `key` bump (`useState` counter) per card forces React to remount the element so the entrance animation re-runs on demand.

### Navigation

- Add a small "Animations playground" link in the `DevPanel` (dev-only surface, fits the existing pattern of dev toggles) so it doesn't clutter the production UI.
